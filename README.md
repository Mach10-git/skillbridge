# SkillBridge

SkillBridge — невеликий frontend SaaS MVP для зіставлення резюме з вакансією. Застосунок показує умовний відсоток збігу, спільні навички, навички для розвитку та чекліст наступних кроків.

## Запуск

Найпростіше — відкрити `index.html` у сучасному браузері. Для локального сервера з кореня теки:

```bash
python -m http.server 8000
```

Потім відкрий `http://localhost:8000`.

Застосунок зроблений на HTML, CSS і чистому JavaScript, тож npm-пакети та ключі API не потрібні. Дані профілю зберігаються у `localStorage` поточного браузера. Кнопка меню профілю дозволяє очистити їх.

## Що працює

- Адаптивна панель аналізу резюме та вакансії.
- Аналіз словника з понад 50 поширених технічних і професійних навичок.
- Індикатор відповідності та списки знайдених/відсутніх навичок.
- Чекліст персональних кроків із запам'ятовуванням прогресу.
- Збереження й видалення вакансій.
- Завантаження текстових файлів TXT, MD і CSV; перетягування файлу в зону завантаження.
- Приклад вакансії для швидкої демонстрації.

## Межі демоверсії

Аналіз виконується за локальним словником ключових слів і не використовує штучний інтелект. Він не оцінює рівень володіння навичкою та може пропускати синоніми чи контекст. Для PDF та DOCX текст потрібно скопіювати в поле вручну. Це демонстраційний frontend-проєкт: у ньому немає бекенду, акаунтів користувачів або синхронізації між пристроями.

## Ідеї для наступної версії

1. Додати бекенд з авторизацією та PostgreSQL.
2. Додати парсинг PDF/DOCX із попереднім переглядом тексту.
3. Розширити таксономію навичок і враховувати рівень вимоги та синоніми.
4. Додати інтеграційні й unit-тести та перевірку доступності.
5. Опційно інтегрувати LLM через серверний API, не передаючи ключ у браузер.
